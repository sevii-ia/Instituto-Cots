# Instituto Cots

This repository contains educational and practice files created during studies and learning activities.

The project is used as a personal learning workspace for experimenting with web development concepts, project structure, and coding practices.

---

## 📚 About

The repository includes:

- Practice exercises
- Educational code examples
- Frontend experiments
- Learning materials
- Small implementation tests
- Coursework-related files

This project is not intended to be a production-ready application.

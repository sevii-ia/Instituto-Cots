## Installation

Clone the repository:

```bash
git clone https://github.com/sevii-ia/Instituto-Cots.git
```

Enter the project folder:

```bash
cd Instituto-Cots
```

## Usage

Open the exercise or project folder you want to review.

For static HTML/CSS/JavaScript exercises, open the `.html` file directly in a browser.

For PHP exercises, use a local server such as XAMPP, WAMP, MAMP, or PHP’s built-in server:

```bash
php -S localhost:8000
```

Then visit:

```text
http://localhost:8000
```
